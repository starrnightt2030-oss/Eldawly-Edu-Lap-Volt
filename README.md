# EduVolt Academy — Interactive Demo v4

Mobile-friendly offline PWA demo. No login/server required.

## Upload to GitHub Pages
Upload all files in this folder directly to the repository root. There are no folders to upload.

## Test flow
1. Open Student Mode.
2. Open Experiments.
3. Start Basic Lamp Circuit.
4. Press Quick Build.
5. Press Run and watch the live measurements.
6. Toggle the switch and Run again to observe the open-circuit state.
7. Submit Experiment and check My Progress.
8. Try Safety Quiz.
9. Teacher Mode shows submissions and local experiment publishing controls.
